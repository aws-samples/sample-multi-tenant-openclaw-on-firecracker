## 技术协议与格式

**HMAC**：基于哈希的消息认证码，用于外部授权签名（`POST /external/authz`）与平台会话 JWT（HS256）。

**JWT**：JSON Web Token。数据面平台会话令牌是平台自签的 HS256（对称密钥）；控制面 console 登录用 Amazon Cognito 签发的 RS256 JWT。

**JWKS**：JSON Web Key Set，Amazon Cognito 暴露的公钥集合端点，用于验证控制面 Cognito RS256 JWT 签名。

**Ed25519 device 认证**：数据面身份根，OpenClaw 原生的非对称设备认证——平台后端用 device 私钥对 gateway challenge 签名，microVM 用冷注入的公钥验签。

**OAuth 2.0 / PKCE**：控制面 console 登录采用的授权码流与代码交换证明密钥扩展（可选，默认关）。

**WebSocket**：数据面实时聊天链路所用的全双工协议。

## 虚拟化技术

**Firecracker**：AWS 开源的轻量级虚拟化技术，在 KVM 之上启动 microVM，具备快速启动与强隔离特性。

**microVM**：由 Firecracker 启动的独立内核轻量虚拟机，平台为每个租户预配一台。

**KVM**：基于内核的虚拟机，Linux 原生虚拟化能力，Firecracker 运行其上。

## AWS 与系统术语

**RBAC**：基于角色的访问控制，平台默认启用，分 viewer、operator、admin 三级。

**IMDS**：实例元数据服务，平台在宿主 iptables 上丢弃虚拟机对其的访问以防凭据盗窃。

**ASG**：Amazon EC2 Auto Scaling 组，管理宿主的弹性伸缩与滚动重建。

**PITR**：时间点恢复，平台为控制面元数据表启用，默认保留 35 天。

**Guardrail**：Amazon Bedrock Guardrails，平台的内容层护栏。

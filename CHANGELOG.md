# Changelog

All notable changes to this project are documented here.

## [1.0.0]

- Initial open-source release of the multi-tenant OpenClaw Pool sample: a
  control plane (AWS CDK) that runs many isolated OpenClaw agents as per-tenant
  Firecracker microVMs on EC2, with per-tenant isolation, auto-scaling, a web
  management console, and a minimal `finance-agent` workspace sample
  (weather + skill-vetter skills).
